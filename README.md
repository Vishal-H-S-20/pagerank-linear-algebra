# PageRank Using Linear Algebra



An interactive Python GUI application that demonstrates Google's PageRank algorithm using matrices, eigenvalues, and eigenvectors.



## Features



- Create and name webpages

- Add links between webpages

- Generate the adjacency matrix

- Calculate the transition matrix and Google matrix

- Display PageRank iterations

- Explore eigenvalues and eigenvectors

- View the final ranking of webpages



## Technologies Used



- Python 3

- Tkinter

- NumPy

- Linear Algebra



## Installation



Install the required dependency:



```bash

python -m pip install -r requirements.txt

```



## Run the Application



```bash

python pagerank\_app.py

```



## How It Works



The application models webpages and their links as a directed graph. It constructs the relevant matrices and iteratively calculates PageRank scores using a damping factor and convergence tolerance.
